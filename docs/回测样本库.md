# 回测样本库

> 用途：每次修改检测引擎（spam-engine.js）后，用真实屏蔽记录做回归测试，防止误伤/漏杀。
> 来源：X 真实屏蔽记录 + 用户反馈的误判案例。
> 规范依据：`docs/PROJECT_RULES.md` 三、TDD 与回测要求。

## 样本来源说明

- `samples/` 目录下每个 JSON 文件 = 一份独立样本批次
- 每个样本字段：`name`（显示名）、`replyText`（回复文本）、`handle`、`pageAuthor`（页面作者，可选）
- `expected`：期望结果 `block`（应屏蔽）/ `pass`（应放行）/ `bio`（需 bio 确认后再定）/ `borderline`（可屏蔽可不屏蔽，不强制）
- 运行回测：`node scripts/regression.js`

## 使用方式

```bash
node scripts/regression.js
```

输出每个样本的检测结果（score / isScam / features），人工核对是否符合 `expected`。

## 维护规则

1. 每次遇到误判案例，立即追加到本表 + samples/ 目录
2. 每次修改检测引擎，必须跑一遍回归
3. expected 为 `bio` 的样本：检测结果里 `needsBioCheck=true` 且最终确认逻辑正确即可
