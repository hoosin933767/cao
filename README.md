# CAO — Clean Accounts Optimizer

让 X/Twitter 回归清净 —— 垃圾回复自动检测、一键屏蔽。

## 安装

1. [下载扩展](extension/cao-extension-v1.0.0.zip) 或从 GitHub [extension/cao-extension-v1.0.0.zip](https://github.com/hoosin933767/cao/raw/master/extension/cao-extension-v1.0.0.zip) 下载
2. 解压到任意文件夹
3. Chrome 地址栏输入 `chrome://extensions` 回车
4. 打开右上角 **开发者模式**
5. 点击左上角 **加载已解压的扩展程序**，选择解压后的文件夹
6. 刷新 `x.com` 即可使用

## 功能

### 自动屏蔽垃圾

在推文详情页（`x.com/xxx/status/...`）自动检测每条评论，从四个维度综合评分，总分 **≤ -4** 触发自动屏蔽 + 隐藏。

#### 关键词（权重从高到低）

| 权重 | 示例 | 说明 |
|---|---|---|
| **-4** | 约炮、裸聊、打飞机、色情、yp 等 | 直接判 spam，稍后即屏蔽 |
| **-3** | 同城约炮、上门、空降、少妇、线下等 | 强信号，需配合其他信号 |
| **-2** | 无偿、骚、交友、反差、私聊、探路等 | 中信号，需叠加其他维度 |
| **-1** | 线更新、同步更新、真实可靠等 | 弱信号，多词叠加才触发 |

#### 引流词

"看简介、点主页、看置顶、点我头像"等行为特征，**独立检测**，不与关键词分类。

#### 综合评分维度

| 维度 | 最高扣分 | 说明 |
|---|---|---|
| **显示名** | -4 | 关键词匹配、装饰 emoji、引流词 |
| **回复文本** | -3 | 关键词匹配（-1）、引流词（-2）、纯 emoji（-2） |
| **Handle** | -2 | 随机生成无元音字母的 handle |
| **跨维度** | -3 | 多维度同时命中时协同扣分 |

> 总分 ≤ -4 触发屏蔽。≤ -6 或显示名含 -4 关键词跳过 bio 二次确认。

### 关键词管理

内置 60+ 系统规则，支持自定义添加/删除关键词，实时生效。

### 屏蔽记录

查看已屏蔽账号（头像 + 名称 + handle），支持解除屏蔽、翻页、从 X 同步官方屏蔽列表。

## 隐私

- 所有数据存储在**本地浏览器**，不上传到任何服务器
- 不需要登录、不需要 API Key、不收集任何个人信息
- 扩展仅操作 X/Twitter 页面 DOM，不读取其他网站
- 源代码完全开源，可审计

## 技术栈

- Manifest V3
- 纯前端，零后端依赖
- 综合特征检测引擎（关键词 + 引流信号 + 混杂度 + 随机 handle）
- 支持 Chrome / Edge
